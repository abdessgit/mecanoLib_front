🔧 MecanoLib

Yo, bienvenue sur la doc de MecanoLib ! Ici, tu vas trouver tout ce qu’il te faut pour piger comment marche l’appli de prise de rendez-vous pour les garages. Pose-toi, c’est simple et cool.

React 19.2 Vite 8.0 React Router 7.13 Framer Motion 12.38 Tailwind CSS 3.4 lucide-react

🏗️ 1. Comment c’est foutu ? 

AppProvider (le cerveau de l’app)
  └── BrowserRouter (pour bouger entre les pages)
        └── AnimatedRoutes (ça gère les transitions stylées)
              ├── MainLayout  →  Navbar + ta page + Footer
              └── CleanLayout →  juste la page, sans chichi

Les outils qu’on utilise

OutilVersionÀ quoi ça sert ?
React19.2Pour faire l’UI, tranquille
Vite8.0Pour builder et dev plus vite
React Router7.13Pour naviguer entre les pages easy
Framer Motion12.38Pour les anims qui claquent
Tailwind CSS3.4Pour le style direct dans le code
lucide-react1.7Pour les icônes stylées
clsx + tailwind-merge—Pour pas se prendre la tête avec les classes CSS

📅 Booking — Prise de rendez-vous

Route : /booking  |  Layout : MainLayout
src/pages/Booking/Booking.jsx

Formulaire multi-étapes en 4 étapes avec barre de progression.

Les 4 étapes

1
Prestation
5 catégories (hover) → liste de prestations avec animation stagger
2
Garage
Recherche par ville via Nominatim + Overpass API OSM (rayon 10 km, max 20 résultats)
3
Date & Heure
14 prochains jours générés dynamiquement + créneaux simulés (Math.random)
4
Vos infos
Formulaire client (prénom, nom, email, tél.) + véhicule (immat, marque, modèle, année) + notes

Catégories de prestations

Cat. 1
Pneumatique & tenue de route
Cat. 2
Freinage & sécurité
Cat. 3
Mécanique & diagnostics
Cat. 4
Entretien & révision
Cat. 5
Électrique & Hybride

⚠️7. Points d'attention

1
Route manquante
/admin/dashboard est référencée dans AdminLogin.jsx après connexion réussie, mais cette route n'est pas déclarée dans App.jsx.
2
Auth côté client
Les identifiants Admin (admin@mecanolib.fr / Admin@2026) et Garage (garage@mecanolib.fr / password) sont en clair dans le code source. À remplacer par une vraie API en production.
3
Espace Client stub
La page /client est un formulaire vide qui retourne toujours une erreur — aucune auth client implémentée.
4
Créneaux aléatoires
À l'étape 3 du Booking, les créneaux disponibles sont générés avec Math.random(), non liés aux données réelles du garage.
5
API OSM externes
La recherche de garages (étape 2) utilise Nominatim + Overpass API (OpenStreetMap). Gratuites, sans clé API, mais soumises aux limites de débit d'OSM.
6
Onglets non implémentés
Dans GarageDashboard, les onglets "Clients" et "Paramètres" existent dans le menu mais n'ont pas de contenu.
